## 13차: 학원 PC 한 대 배포 준비와 리허설 (2026-10-13)

배포 방식을 'A. 학원 PC 한 대(그 PC에서만 사용)'로 정하고 운영 준비를 정비했다.

- `npm run setup:prod` 추가: Node 버전·`.env.prod`·관리자 아이디 형식·접속 주소(127.0.0.1)·웹 빌드·운영 DB 분리를 점검하고, `.env.prod`가 없으면 예시로 만들며 초기 관리자 비밀번호를 무작위로 넣는다(화면에 출력하지 않음).
- `npm run backup:prod` 추가: `.env.prod`를 읽어 운영 DB를 백업. 예전에는 매일 백업 작업이 `.env.prod`의 백업 폴더를 무시했고, 손으로 `npm run backup`을 치면 데모 DB가 백업됐다.
- 운영 실행기는 창 없이 실행되면(`--log-file`) 기록을 `server/data/logs/server-YYYY-MM.log`에 남긴다. 작업 스케줄러는 서버를 숨긴 창으로 띄워 창을 닫아 꺼지는 일을 막고, 바탕화면 바로가기를 만든다.

**리허설** (임시 폴더의 환경 파일·DB·백업·로그를 `WB_ENV_FILE`로 지정, 포트 3999. 실제 `.env.prod`·운영 DB·작업 스케줄러는 건드리지 않음)

## 15차: 기존 Cloudflare 터널로 외부 접속 연결 (2026-10-13)

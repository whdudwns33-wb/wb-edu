## 미검증 (구현은 되어 있음)

- 엑셀 파일을 실제로 열어 시트·셀 값 대조 (API로 생성·크기·MIME만 확인)
- 브라우저에서 `prompt` 기반 입력(휴강 사유·보강일·제외 사유) 흐름 — API로는 검증
- 두 수업 맞바꾸기·특정 날짜 고정 모달의 브라우저 조작 — 단위·API로 검증
- 강사 계정으로의 브라우저 로그인·권한 UI — API로 검증(403, 접근 제한)
- 설정 화면의 휴일 수정·사용자 추가의 브라우저 조작 — API로 검증
- 표 붙여넣기 가져오기 모달의 브라우저 조작 — 파서·API로 검증
- 동시 수정 충돌(409) 화면 처리 — API로 검증, 화면의 '최신 버전 불러오기'는 미검증

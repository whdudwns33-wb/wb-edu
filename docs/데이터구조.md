# 데이터 구조

타입 정의 원본: [shared/src/types.ts](../shared/src/types.ts). 모든 연결은 화면 표시명이 아니라 고유 식별자(UUID)로 합니다.

## 저장 방식

- `node:sqlite` 단일 파일. 집합(aggregate) 단위 문서 저장: `docs(kind, id, data JSON, version, updated_at, archived, is_sample)`.
- `version`: 낙관적 동시성 제어. 저장 요청은 현재 `version`을 함께 보내야 하며, 다르면 **409** (조용히 덮어쓰지 않음).
- `archived`: 삭제 대신 보관. 계획에서 항목을 제외해도 교재 원본은 삭제되지 않습니다.
- `is_sample`: 가상 샘플 표시. 설정 화면에서 샘플만 일괄 삭제할 수 있습니다. 데모 DB(`wb-edu.demo.sqlite`)와 운영 DB(`wb-edu.sqlite`)는 파일이 분리됩니다.
- `users`, `sessions`, `audit` 는 관계형 테이블.

| 실행 계획 및 버전 | `Plan` | title, target, classOrStudentRef(선택·복제 시 제외), curriculumId, snapshot(과정·교재 스냅샷), settings, lessons[], assignments[], unassigned[], records[], understandingChecks[], status(초안/확정), planVersion, endDateComputed, history[], author, reviewer, requiredObjectiveIds[], allowedUserIds[] |
| 계획 스냅샷 | `PlanSnapshot` | curriculumId/Title/Version, compositionMode, takenAt, sessions[], textbooks[]{id, title, edition, textbookVersion, items[]…}, advance? |
| 편성 설정 | `PlanSettings` | startDate, endDate, targetDate, weekdays[], minutesPerLesson, reviewMinutes, bufferMinutes, mode(기간 우선/속도 우선), academicYearStartMonth, holidaySetIds[], offDays[], makeupDays[], fixedEvents[], tracks{review, advance, advanceWeekdays, currentMinMinutes}, maxDays |

| 학습항목 배정 | `Assignment` | lessonId, sessionId/sessionOrder/entryId(출처 차시), textbookId, itemId, track, activity, minutes, portion?/fraction?, order, locked(고정), continuedFrom?(이어서 진행 원본) |
| 미배정 | `UnassignedEntry` | 배정과 같은 식별 정보 + reason(총시간 부족/분할 불가/순서 제약/고정 일정 충돌/목표일 초과/제외) + detail + continuedFrom?(이어서 진행한 남은 범위가 미배정이 된 경우 원래 배정) |

| 사용자 | `User` | username, displayName, role(admin/teacher), active. 비밀번호는 scrypt 해시 |

## 식별자와 연결 규칙

- 배정 → 학습항목은 `textbookId + itemId`로, 교재 원본이 아니라 **계획 스냅샷** 안의 항목을 가리킵니다.
- 이어서 진행 배정은 `continuedFrom`으로 원래 배정과 연결되며, 완료량은 항목 단위 합집합으로 계산되어 중복 집계되지 않습니다.
- 과정 복제는 새 id를 부여하고 검토 의견·버전·학생정보를 복제하지 않습니다. 계획 복제는 기록·이해 확인·이력·반/학생 식별·허용 강사를 제외합니다.

## 권한 (서버에서 검사)

| 작업 | 관리자 | 강사 |
|---|---|---|
| 교재·학습목표·표준과정·휴일·양식·운영 설정·사용자 관리 | O | 조회만 (과정 검토 의견은 가능) |
| 계획 만들기·수정·기록·확정·복제 | 모든 계획 | 자기가 만든 계획 + 허용 강사로 지정된 계획 |
| 샘플 데이터 일괄 삭제 | O | X |

인증: 세션 쿠키(`wb_session`, httpOnly, 14일). 비밀번호는 `scrypt`로 해시합니다.
